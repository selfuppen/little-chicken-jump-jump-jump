# 小鸡跳跳跳

HTML、CSS、JavaScript 与 Three.js / WebGL 编写的可爱风 3D 三赛道小游戏。小鸡朝前自动奔跑，镜头从身后跟随，两条分隔线将跑道分成左、中、右三条赛道。

## 本地试玩

在线试玩：https://selfuppen.github.io/little-chicken-jump-jump-jump/

安装 Node.js 20 或以上版本，运行：

```sh
npm install
npm run dev
```

在支持 WebGL 2 的浏览器打开 http://localhost:5173 。电脑用空格跳跃，鼠标左键向左移动一格、右键向右移动一格（点击游戏画面）；手机左右滑动换道，轻触画面或点击「跳一下」跳跃。每次滑动只换一格，最边上继续向外操作无效。P / Esc 暂停或继续，切换标签页自动暂停。Three.js 由本地依赖提供，安装后运行不需要 CDN。

## 规则

- 每排随机出现 0、1、2 或 3 个障碍，随机占用不同赛道；整排空白和三条赛道全有障碍都会出现。跳过或换道躲开障碍，每个加 1 分。空跳与穿梭世界不加分。
- 起始速度 260，每分增加 0.8，300 分后速度上限为 500。
- 三颗爱心，碰撞扣一颗；碰撞后无敌 1.2 秒。
- 爱心耗尽后冻结画面，2.5 秒后才显示「再试一次」。点击按钮或重新按下空格 / 回车可开始新一局；持续按住的按键不会自动重开。
- 海洋跳跃节奏为草地的 1.35 倍，保持跳跃高度，滞空时间缩短约 26%，回到草地恢复原节奏。
- 暂停按钮使用更大的实色背景和黑色文字；桌面按 P / Esc 可以暂停或继续，手机点击按钮。
- 管道单独出现在随机赛道，出现间隔也会变化：草地约 14～24 个常规障碍，海洋约 6～12 个常规障碍后出现（完整生成当前排后检查）。同赛道从上方落进开口进入下一世界；侧面碰撞扣爱心。草地运行在海洋中冻结，回来后至少有 1.5 秒安全时间。
- 海洋障碍以塑料瓶、黑色塑料袋和透明塑料袋为主。旧渔网和落网合计出现概率为 1.5%，平均每 100 个海洋普通障碍约 1～2 个；单个随机样本的数量会浮动。透明袋带半透明材质和轮廓褶皱。
- 碰到渔网会扣一颗爱心，粘住 0.7 秒后自动挣脱。粘住期间不能跳跃或换道，关卡推进暂缓；无敌保护和同一渔网只扣一次血仍生效。
- 深绿色落网先预警、再落下。预警时间由 1.7 秒随分数逐渐缩短至最低 0.95 秒，落下用时 0.42 秒。含落网的一整排在预警期间保持原位，落地后一起接近，下一排保留安全间隔。可以换道或跳过。
- 达到 1000 分通关，每局独立，不存档。

## 验证

```sh
npm test
```

`src/game.js` 是与画面无关的游戏状态，`src/renderer.js` 负责 3D 场景、模型、光照与绘制，`src/app.js` 连接输入与界面。换道碰撞使用实际移动位置，不会瞬移躲过障碍。静态服务器支持 `PORT` 环境变量，默认 5173。

## GitHub Pages 发布

`npm run build` 将网页、源码和需要的 Three.js 模块复制到 `dist/`，所有资源使用相对路径，支持仓库子目录。推送到 `main` 后，GitHub Actions 自动安装依赖、运行测试并部署到 GitHub Pages。仓库的 Pages 发布来源设为 GitHub Actions。
